# 《活人感 2079 重制版》交接进度摘要（最新版）

打包依据：桌面项目当前文件（源码与文档以本机最新修改为准）。

## 做到哪了
- 网页 Three.js 3D 游戏，主角奶蛙
- 8 个街区任务全部接入并可跑通：魔都、东京、大苹果、海滩、巴黎、金字塔、冰岛、老家
- 主线可跑到自由闯荡
- 15 个生成模型接入（10 个 Lux3D + 5 个 Tripo：自由奶蛙像、黄出租、救生塔、火烈鸟泳圈、招财猫），全部带代码画兜底

1. 解压本包
2. 双击 `scripts/launch/启动游戏.bat`（Windows）或 `scripts/launch/启动游戏.command`（Mac），或本地静态服务打开 `index.html`
3. 细节见 `交接说明.md`、`开发日志.md`
