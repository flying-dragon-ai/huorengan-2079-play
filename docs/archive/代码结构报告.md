### 4.2 启动链路

```
双击 启动游戏.bat / .command
  └─ python tools/serve.py 2079        # 127.0.0.1，no-cache，ThreadingHTTPServer
     └─ Chrome --app=http://127.0.0.1:2079/index.html[?auto=1|?dev=1]
        └─ index.html 检查 location.protocol === 'file:' → 给出提示（ES 模块不能走 file://）
           └─ <script type="module" src="./src/main.js">
              └─ boot(): new Game(#c) → game.init(progress)
                 ├─ preload(MODEL_CONF 全部 GLB)          0.02 → 0.38
                 ├─ preloadGen()（读 gen/manifest.json）   0.38
                 ├─ new Hall(pipe)                        0.40
                 ├─ new Environment(pipe, scene)          0.49
                 ├─ new Island(scene, env)                0.58  ← 建地形/路网/楼/广场/8 街区
                 ├─ Player / CameraRig / NPC / FX / Guide / Districts   0.76
                 ├─ bindPhotoControls(game)（观景模式）
                 ├─ renderer.compile(hall.scene)          0.88
                 └─ state = 'title' → loop()
```

`init()` 的每个阶段都 `await requestAnimationFrame + setTimeout(0)`，让加载进度条真正刷新，避免长任务把主线程锁死。

### 4.3 主循环

`Game.loop()`（`src/game/game.js:229`）单 `requestAnimationFrame` 驱动，顺序固定：

```
1  dt = min(raw, 1/20)                     # 掉帧保护
2  fps 指数平滑（0.97/0.03）
3  观景模式分支：photo → updatePhoto(dt) → return（世界冻结）
4  H 帮助 / M 大地图：paused || mapOpen → 只 render(0) → return（画面定格）
5  time += dt；Timeline.update(dt)
6  timeScale 向 0.22（慢动作）或 1 插值；wdt = dt * timeScale
7  state ∈ {title, hall} → updateHall(dt)；否则 updateWorld(wdt)
8  flash 衰减 → pipe.g.uFlash
9  ui.update(dt)
10 假过场 pptT > 0 → 每 0.45s 才 render 一次（"卡成 PPT"）
   否则 pipe.render(dt, time)
11 input.endFrame()                        # 清 pressed / 鼠标增量
```

`updateWorld(dt)` 的固定顺序（`game.js:485`）：

```
输入虚拟化（autoDrive / devVirt）→ E 交互 → Q 大笑 → R 回路上
→ 降落伞付费弹窗 → 活人感过高检测 → player.update → 事件派发
→ CameraRig（dive / splat / 常规）→ 导航目标 + 屏幕标记 + 小地图路线
→ guide.update → 卡住检测 → 大奶蛙变身
→ island.update → env.update → 袋鼠 → 牛来 → 路人 → 粒子 → 冲击波
→ 主线任务 → 催星追兵 → 画质分级 → HUD → 袋鼠抢单 → 任务列表
→ districts.update → 地面箭头 → 雕像摆动
```

### 4.4 双状态机

游戏用**两个正交状态机**：`state` 管场景/模式，`phase` 管主线进度。

```
state:  loading → title → hall → dive → roam → finale → free
                ↑                ↓
                └── (title 可直进观景 photo)

phase:  (空) → getbike → order → pickup → deliver → night
              → laughReady → laughing → finale → free
```

| state | 含义 | 关键行为 |
|---|---|---|
| `loading` | 资源加载 | 进度条 + 加载小贴士轮播 |
| `title` | 标题画面 | 大厅镜头缓慢摆动；空格/回车/点击开始；`#tour` 直进观景 |
| `hall` | 人生舱大厅 | 十连抽卡（`ui.drawCards`），可空格跳过 |
| `dive` | 高空空降 | 330 米弹降落伞付费窗；不买摔成饼 |
| `roam` | 地面主线 | 骑电驴、取餐、送单、入夜、大笑 |
| `finale` | 烟花结局 | `finaleCam` 接管镜头 |
| `free` | 自由闯荡 | 街区任务全开、观景全开、招队友 |

| phase | 触发 | 目标 |
|---|---|---|
| `getbike` | 摔成饼后 | 走到电驴旁按 E |
| `order` / `pickup` | 上车后 | 去魔都咖啡店取餐（限时） |
| `deliver` | 取到咖啡 | 送到海边七大姑，袋鼠抢单、亲戚追 |
| `night` | 送达 | 撞东西攒笑点，霓虹亮起 |
| `laughReady` | 笑点满 | 按 Q |
| `laughing` | 按 Q | 慢动作 + 冲击波 + 大奶蛙变身 |
| `finale` → `free` | 烟花结束 | 自由闯荡 |


### 4.5 街区组件契约

每个街区是 `src/world/districts/*.js` 里的一个类，由 `Island.buildDistrictKits()` 统一实例化并塞进 `island.districts`，再由 `Districts` 管理器驱动。契约字段：

```js
class SomeDistrict {
  constructor(island) {
    this.id, this.name, this.tagline, this.color   // 身份与配色
    this.center = [x, z]                            // 大地图标注
    this.bounds = [x0, x1, z0, z1]                  // 进入判定矩形
    this.gags = new Gags()                          // 当地笑点触发器集合
    this.quest = {                                  // 当地任务
      title, short, kind, time, gain, at,           // kind: 打/躲/送/撞/跑图
      intro, goal, cheer,
      start(g, a), update(g, dt, a), end(g, win, a)
    };
    this.views = [[name, 'eyeX,eyeY,eyeZ', 'tgtX,tgtY,tgtZ', hour], ...]  // 验收机位
    this.marks = [...]                              // 大地图额外标记
  }
  update(g, dt, inside) {}      // 每帧；inside 表示玩家是否在 bounds 内
  startQuest(g, a) {}           // 接任务
  updateQuest(g, dt, a) {}      // 返回 { note, win, fail }
  endQuest(g, win, a) {}        // 返回结算文案数组
  testStep(g) {}                // 机器人验收用：把任务推进一步
  testGag(g) {}                 // 机器人验收用：强制触发笑点
  animate(dt, t) {}             // 纯动画（电车、摩天轮、极光）
  onEnter(g) / init(g)          // 可选钩子
}
```

`Districts` 管理器（`src/game/districts.js`）负责：进街区大字横幅、笑点计数、任务光圈（`questRing`）、E 键接任务、倒计时、结算活人感、任务列表分组、大地图标记、导航目标选择、`?dev=1` 开发工具。主线在跑（`MAIN_BUSY = ['pickup','deliver','order']`）时禁止接街区任务。

### 4.6 渲染管线

`src/gfx/pipeline.js` 的 `Pipeline` 类：

```
WebGLRenderer（antialias, HDR 半浮点 RT, ACESFilmic, PCFShadowMap）
  └─ EffectComposer
       ├─ RenderPass(scene, camera)
       ├─ ShaderPass(SanitizeShader)   # NaN → 0，颜色 clamp 到 200，防辉光糊成黑屏
       ├─ UnrealBloomPass              # 阈值 1.35（过曝修复后上调）
       ├─ ShaderPass(GradeShader)      # 自定义调色
       └─ OutputPass                   # 色调映射 + sRGB
```

`GradeShader` 一个 pass 里做了七件事，全部由 uniform 驱动：

| uniform | 作用 |
|---|---|
| `uLow` / `uReveal` / `uPix` | 360P 灰盒：像素化 + 去饱和 + 圆形揭示边缘发光（开场"画质掉到 360P → 骑电驴恢复"） |
| `uSat` / `uWarm` | 饱和度、青橙分离调色 |
| `uVig` / `uGrain` / `uCA` | 暗角、胶片颗粒、色差 |
| `uFlash` | 白闪（大笑、撞击） |
| `uLetter` | 电影黑边（结局） |

另有两处工程性防御，写在文件顶部注释里：

1. `THREE.ShaderChunk.roughnessmap_fragment` 全局注入 `roughnessFactor = max(roughnessFactor, 0.1)`——粗糙度过低时太阳高光会超过半精度浮点上限 65504 变成 Inf，辉光后整块画面变黑。
2. `SanitizeShader` 在辉光前清洗 NaN/Inf。

`Environment` 类（同文件）负责天空（`Sky`）、海面（`Water`）、PMREM 环境反射、太阳高度驱动的昼夜与曝光；`environmentIntensity` 随太阳高度从 0.75 压到 0.22（正午过曝修复）。

### 4.7 资源加载与降级策略

三层降级，保证"模型缺失也能玩"：

```
1. GLB（Lux3D / Tripo 生成，meshopt 压缩）
     ↓ 缺失或加载失败
2. 代码画的备用模型（models.js 的 FALLBACK 表：电饭煲、纸箱、球体拼装）
     ↓ 需要人形剪影时
3. 纸板立牌 standee()（Canvas 画脸 + 平面）
```

- `MODEL_CONF`（`src/actors/models.js`）是唯一模型注册表：`{ h: 目标高度, yaw: 朝向修正, file: 文件名, tripo: true }`，共 22 项（主角、袋鼠、牛来、电驴、大奶蛙、17 个热梗路人）。
- `preload()` 并发加载并缓存；`getModel()` 返回 `SkeletonUtils.clone` 的实例（蒙皮安全）。
- `preloadGen()` 读 `assets/models/gen/manifest.json`（10 个生成模型），`genModel(names, h)` / `genOr(names, h, fallback)` 按名字取，取不到走 fallback。
- 单文件版（`dist/`）通过 `<html data-models="procedural">` 标记跳过全部 GLB，只用代码模型。

### 4.8 UI / 音频 / 数据层

- **UI（`src/game/ui.js`）**：纯 DOM 操作。字幕、目标、倒计时、活人感条、催星、手机消息、弹幕（固定 5 条轨道，右侧留 30vw 避开任务面板）、小地图（Canvas2D，预渲染底图 `drawMapBg`）、大地图（1024×1024 Canvas2D）、抽卡翻牌、结算弹窗、片尾。
- **音频（`src/audio/audio.js`）**：`AudioContext` 单例。14 个录音采样（`SAMPLES` 表带起播偏移与时长，梗音效互斥防吵）、程序化 `tone()` / `noise()` 合成（boing/crash/splat/pop/coin/ding/upgrade）、引擎声与风声的持续噪声节点、芯片音乐电台、`speechSynthesis` 选中文语音念台词。单文件版把采样以 base64 塞进 `<script id="sound-bank">`。
- **数据（`src/data/text.js`）**：全部文案与梗集中一处——`LINES`（分角色台词）、`DANMAKU`、`MEMES`、`MEME3D`、`MEME_SPOTS`、`CHOIR`、`ROAD_MEME`、`GACHA_N`（十连抽卡名）、`TIPS`、`CARD`。换梗只改这一个文件。

## 8. 构建、运行与打包

### 8.1 开发运行

```bash
# Windows
双击 启动游戏.bat            # 起 serve.py:2079 + Chrome --app 全屏
# macOS
双击 启动游戏.command
# 手动
python tools/serve.py 2079   # 127.0.0.1，Cache-Control: no-cache，队列 64
```

URL 参数：

| 参数 | 作用 |
|---|---|
| `?auto=1` | 机器人自动演示，从开场玩到结局（需先点一下画面解锁音频） |
| `?dev=1` | 挂载 `__game.dev`：`jump(x,z)` / `tp(x,z,yaw)` / `ride(x,z)` |
| `?view=<id>` | 直接进某个观景机位 |
| `?debugLoad=1` | 控制台打印 mesh/bone/vertex 统计 |

### 8.2 单文件打包

```bash
python tools/build_portable.py          # 需要 esbuild 在 PATH 或设 ESBUILD
# → dist/活人感2079.html  3.81 MB
```

`build_portable.py` 做的事：

1. `esbuild src/main.js --bundle --minify-whitespace --minify-syntax --format=esm --charset=utf8 --alias:three=... --alias:three/addons=... --target=es2022`
2. 转义 bundle 里的 `</script`
3. 给 `<html>` 打 `data-models="procedural"`（跳过 GLB）
4. 删掉 importmap
5. 把 `naiwa-belly-laugh.gif` 与 14 个音频文件 base64 内嵌
6. 把 `assets/来源.md` 作为注释塞进产物
7. 原子替换（临时文件 + `os.replace`）

**不要改回 `--minify`**：标识符重命名在 vendor/three 体积下会卡死（开发日志有记录）。

### 8.3 观景版

`browser/` 是另一套独立实现（`browser/src/main.js` + `browser/components/*`），只做自由浏览，无玩法。`python browser/build.py` → `dist/地球村-自由浏览.html`（828 KB）。它与 `src/` 不共享代码，只共享 `vendor/three/`。

全部基于 `tools/cdp.mjs`——一个 50 行的裸 CDP 客户端（Node 22 自带 `WebSocket`，零依赖），负责拉起 headless Chrome、注入键盘/鼠标、截图、收集 console 与异常。

## 14. 已知缺口与结构风险

| 项 | 说明 | 影响 |
|---|---|---|
| `island.js` / `game.js` 过大 | 974 / 901 行，单类承担地形、楼体、广场、道具、碰撞与全部主线编排 | 改动易冲突；建议按 `terrain / buildings / props / colliders` 与 `mission / camera / auto` 拆分 |
| 街区组件与 `island.js` 双向耦合 | 街区构造时读 `island.shRows`、`island.cafe`、`island.auntSpot` 等由 `island.js` 预置的字段 | 新增街区必须知道 `island.js` 的内部约定 |
| 常量跨模块反向引用 | `guide.js`、`ui.js` 从 `island.js` 导入 `XR/ZR/BEACH_Z/ROAD_W/shoreEdge` | 世界层与 UI 层耦合，改路网会波及 UI |
| 奶蛙新模型未接入 | 41 骨、188 万面，绑骨服务连续拒绝（`MODEL_NOT_RIGGABLE`），全岛蒙皮渲染会顶到测试 Chrome 内存上限 | 主角仍是旧模型；`naiwa_animated.glb` 只在诊断页验证过 |
| 资产管线不可复现 | `tools/lux3d/` 与 `lux3d_generate.mjs` 缺失 | 生成模型无法重新产出，只能沿用现有 GLB |
| 单文件版与标准版内容不同 | `dist/` 用程序化模型，`index.html` 用 GLB | 两版视觉不一致，需分别验收 |
| 无自动化单元测试 | 全部验收依赖 headless Chrome 端到端脚本 | 逻辑回归只能靠机器人跑全程 |
| 无存档 | 进度只在内存 | 刷新即从头开始 |
| 视觉待办 | 冰岛水陆过渡与夜景、巴黎橱窗纵深、东京立体店面；原始参考图不在包内 | 无法逐图对照复刻 |
