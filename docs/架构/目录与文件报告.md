### 1.2 根目录里的实验台（autoresearch）—— 为什么它们允许待在根

标准是「根目录只放一进门就该看见的东西」，这 5 个 `autoresearch.*` 是**唯一的结构性例外**，
理由不是"懒得挪"，是 **harness 按固定路径在根调用它们**（`autoresearch.md` 第 7、8 行直接写
`bash autoresearch.sh` / `bash autoresearch.checks.sh`，且 checks 会在每次跑分通过后自动执行）。
挪走 = 实验台失效。

| 文件 | 作用 | 入库 | 可重生成 |
|---|---|---|---|
| `autoresearch.md` | 测什么、怎么跑、指标定义（`METRIC worst_scene_p95_ms`，越低越好） | ✅ | ❌ 人写的 |
| `autoresearch.sh` | 跑分入口，`cd` 到仓库根后调 `tools/qa/bench_mobile.mjs` | ✅ | ❌ |
| `autoresearch.checks.sh` | 跑分通过后自动跑的门禁：`npm run lint` + `npm test` + `npm run build` | ✅ | ❌ |
| `autoresearch.ideas.md` | 待验证假设清单（跨轮次累积） | ✅ | ❌ |
| `autoresearch.jsonl` | 每次实验的流水（**追加写**，多分支并行会冲突） | ✅ | ❌ 是记录本体 |

**产物落在哪**（全部 gitignore，见 `.gitignore` 的「缓存与本地实验产物」段）：

| 路径 | 内容 | 规则 |
|---|---|---|
| `.cache/autoresearch/*.json` | 每轮跑分的原始帧样本、P95/P99、GPU 串、截图 | `.cache/` |
| `.cache/diag_*.json` | 诊断脚本的临时落盘 | `.cache/` |
| `.cache/probe*.mjs` | 一次性探针脚本 | `.cache/` |
| `tests/e2e/shots/<日期>/` | QA 与 diag 脚本的截图 | `tests/e2e/shots/` |

**`.cache/` 必须同时出现在三份 ignore 里**（2026-11-26 实测补上）：
`.gitignore` 早就有，但 `eslint.config.js` 和 `.prettierignore` 之前**没有** ——
`npm run lint` 会把 `.cache/` 下的探针脚本当真源码 lint，生成物能把 CI 门禁搞红。

**`优化计划.md` 是唯一该走的结构性问题**：它是本轮手机横屏适配的对外说明，全文没有代码引用它，
按「根目录文档必须归位 `docs/`」的规矩应该进 `docs/`。放在根只是因为研究分支还在跑。

## 10. 依赖关系（实测，目录粒度）

```
index.html ──▶ src/main.js ──▶ game ──▶ world ──▶ gfx ──▶ core
viewer.html ─▶ src/viewer/main.js（独立，只依赖 three）

横向边：
  game  ─▶ actors, audio, data, gfx, world
  world ─▶ actors, core, gfx
  actors ─▶ core, data, gfx, world
  gfx   ─▶ core
  audio ─▶ core
  data  ─▶ （只依赖 three）
  core  ─▶ （零依赖）
```

**实测边数**：`world → actors` 16 条、`actors → world` 2 条（`player.js:5`、`camera-rig.js:4` 的 `groundH`）。目录粒度上是双向的，但**文件粒度无运行时环**——`world → actors` 的链条走到 `npc/kangaroo.js` 就停了。

**孤儿检查**：63 个 JS 从两个 HTML 入口全部可达，0 孤儿。
