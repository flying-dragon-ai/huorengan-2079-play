# 《活人感 2079 重制版》交接说明

> 最后更新：2026-11-18 晚（本地时间）· 更新人：开发助手
> 任何 AI 或人拿到这份文件就能接手。每做完一个街区、或每干 30 分钟就更新一次。运行记录在 `开发日志.md`。

## 1. 项目是什么
- 网页 3D 游戏，Three.js r180（`vendor/three/`，不联网），主角奶蛙。第一原则：让人笑出声；第二：好看。
- 总设计：`工程书_v2.pdf`；分批计划：`开发计划.md`；玩家说明：`怎么玩.txt`。
- 流程：人生舱大厅 → 十连抽 → 空降摔成饼（360P）→ 骑电驴恢复画质 → 魔都取咖啡 → 东京 → 被牛来顶飞 → 海边送给七大姑 → 入夜 → Q 捧腹大笑 → 烟花 → 自由闯荡。
- 第 2 批起每个街区是一个独立组件（`src/world/districts/*.js`），有地标、当地任务（60–120 秒，打/躲/送）、≥3 个只在当地出现的笑点、当地路人和道具，接进大地图、任务列表、导航 ◆ 和活人感结算。

## 2. 怎么启动 / 测试 / 打包（本地，项目目录以解压后文件夹为准）
> **2026-11-19 架构重构后**：不再需要 Python。静态服务、打包、验收全部走 Node（≥ 20.19）。
> 先 `npm ci` 装开发期工具（eslint / prettier / vitest / esbuild），然后：
> - 起服务：`npm run dev`（= `node scripts/serve.mjs`，127.0.0.1:2079，no-cache，队列 64）
> - 打包：`npm run build` / `npm run build:viewer`（= `scripts/build-*.mjs`，esbuild JS API）
> - 门禁：`npm run check`（lint + test + 两个 build）
> 双击 `scripts/launch/启动游戏.bat` / `scripts/launch/启动游戏.command` 等价于起服务 + Chrome 全屏，可传 `"?auto=1"` / `"?dev=1"`。
> `tools/qa/cdp.mjs` 已跨平台：自动找 Mac/Windows 的 Chrome，`CHROME_PATH` 可覆盖；截图目录自动创建。
- 玩：双击 `scripts/launch/启动游戏.command`（`node scripts/serve.mjs` 在 127.0.0.1:2079 起静态服务，Chrome 全屏打开）。服务已在跑就直接开 `http://127.0.0.1:2079/index.html`。
- 自动演示：`./scripts/launch/启动游戏.command '?auto=1'`，点一下画面，机器人从开场玩到结局。
- 开发跳关：`index.html?dev=1`，控制台里 `__game.dev.jump(x, z)`（跳过开场、骑电驴站在 x,z，自由闯荡状态）、`__game.dev.tp(x,z,yaw)`、`__game.dev.ride(x,z)`（电驴自己骑过去，`ride()` 停）。
- 机器人验收（Node 22+ 自带 WebSocket，不用装包；用本机 Chrome 无头模式）：
  - `node tools/qa/check_entries.mjs` —— 两个观景入口（标题「先逛中央广场」、送单途中按 P）。
  - `node tools/qa/check_district.mjs <街区id>` —— 拍场景、逐个触发笑点、接当地任务让机器人做完、开大地图截图、汇总控制台报错。id：`shanghai` `tokyo` `bigapple` `beach` `paris` `pyramid` `iceland` `hometown`。
  - `node tools/qa/check_full.mjs` —— 自动演示从大厅跑到自由闯荡。
  - `node tools/qa/check_offline.mjs` —— 以 `file://` 打开 `dist/活人感2079.html`，确认离线单文件能启动、8 街区齐全、零报错。
  - 三个 check 脚本都认 `BASE_URL` 环境变量覆盖被测入口。
  - `tools/qa/cdp.mjs` 是这些脚本用的无头 Chrome 小库。
- 截图放 `tests/e2e/shots/<日期>/`（每天一个文件夹；三个 check 脚本第一个参数可指定输出目录，目录不存在会自动创建）。
- 打包单文件：`npm run build` → `dist/活人感2079.html`（单文件版用代码画的模型，不读 GLB）；`npm run build:viewer` → `dist/地球村-自由浏览.html`。**不要改回 `--minify`**：标识符重命名在 vendor/three 下会卡死；现在用 `--minify-whitespace --minify-syntax`，约 0.2 秒、3.81MB。

## 9. 重构后新增：单测与已知问题

`npm test` 跑 `tests/unit/` 下 8 个文件、135 条断言，纯逻辑、不依赖 WebGL/DOM，约 1.3 秒。
覆盖 `core/math`、`core/util`（Timeline）、`core/config` 不变量、`data/text` 完整性、
`data/model-registry`（含 22 个 GLB 落盘校验）、`data/quest-config`、`game/guide` 路网最短路、
`game/districts` 结算增益。

写单测时发现三处**重构前就存在**的行为，本轮按「行为保持」原则**没有修**，记录在此：

1. `src/core/util.js` `Timeline.update` 按 `at()` 的调用顺序触发，不按到期时间排序。
   后注册但延迟更短的回调会排在前面。当前代码里所有用法都是递增延迟，所以没暴露。
   修法：`due.sort((x, y) => x.t - y.t)` 再 `forEach`。
2. `src/core/math.js` `smooth(a, b, x)` 在 `a === b` 时返回 `NaN`（`0/0`）。
   任何用两个相等值当区间的调用（零长度淡入淡出）会把 `NaN` 传下去。
   修法：`b === a ? (x < a ? 0 : 1) : …`。
3. `src/game/districts.js` `finish()` / `abort()` 在没有 active 任务时不是空操作，而是
   解引用 `null.d` 抛 `TypeError`。它确实挡住了重复结算，但是靠崩溃挡的。
   如果计时器回调和胜利判定同时触发，会打断这一帧。修法：开头 `if (!this.active) return;`。

另外 `routeTo` 会输出重复的相邻点（`[[50,0],[50,0],…]`），对导航线渲染无害，只是多几个顶点。
